# Blinkit-Sales-Analysis-Using-Python

## Overview

This project analyzes Blinkit sales data using Python to identify sales trends, product performance, customer preferences, and outlet characteristics. The analysis helps uncover valuable business insights through data cleaning, exploratory data analysis (EDA), and visualization.

---

## Dataset

The dataset contains information about products, sales, outlets, and customer ratings.

### Features

* Item Identifier
* Item Fat Content
* Item Type
* Item Weight
* Item Visibility
* Sales
* Rating
* Outlet Identifier
* Outlet Size
* Outlet Location Type
* Outlet Type
* Outlet Establishment Year
